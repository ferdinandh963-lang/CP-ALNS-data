# CP-ALNS Data

Baseline schedules and best reported results by scenario for the CP-ALNS reactive scheduling study.

## Contents

| File | Description |
| --- | --- |
| `Baseline data/P70.xlsx` | Baseline data for case P70 |
| `Baseline data/P150.xlsx` | Baseline data for case P150 |
| `Baseline data/P300.xlsx` | Baseline data for case P300 |
| `Baseline data/P750.xlsx` | Baseline data for case P750 |
| `Best Results by Scenario.xlsx` | Best reported results for the scenarios included in the workbook |

The five Excel workbooks are preserved byte-for-byte from the files selected by the repository owner. “Best” denotes the reported experimental results; this repository does not independently certify global optimality.

## Access and version

This repository is private during manuscript preparation and submission. Public access will be enabled separately by the owner after submission. A private repository link is accessible only to authorized collaborators.

This initial data snapshot was prepared on 2026-11-06. `SHA256SUMS.txt` records the checksums of the five original data files. `data_manifest.json` records their relative paths, sizes, and checksums.
